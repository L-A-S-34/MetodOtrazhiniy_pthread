РЕШЕНИЕ СЛАУ МЕТОДОМ ОТРАЖЕНИЙ С ИСПОЛЬЗОВАНИЕМ PTHREAD

Студент: Лизунов Артём Сергеевич 304 группа мехмат

Описание:
Программа решает СЛАУ методом отражений. 

Код реализован на C++ с использованием универсальных шаблонов, библиотеки pthread и алгоритмом Кэхена,
что позволяет параллельно оценивать точность расчетов для типов 
данных 'double' и 'long double'

Структура:
- CMakeLists.txt  : Конфигурационный файл сборки CMake
- main.cpp        : Главный управляющий модуль программы
- init.h          : Инициализация матриц по формулам и чтение из файла
- SolvePthreads.h : Реализация метода отражений
- README.txt      : Данное руководство
- Results.xlsx    : Некоторые экспериментальные результаты работы

Сборка проекта:

 $ mkdir build
 $ cd build
 $ cmake ..
 $ make


Запуск генерации матриц по формулам (k = 1..4):
Синтаксис: ./solution <n> <m> <k> <num_threads>
Пример (Размерность 10, вывод 7 элементов, матрица Гильберта k=4, число нитей num_threads=2):
$ ./solution 10 7 4 2

Запуск с чтением матрицы из файла (k = 0):
Синтаксис: ./solution <n> <m> 0 <имя_файла> <num_threads>
(Перед запуском скопируйте файл с матрицей, например a.txt, в папку build)
$ ./solution 3 3 0 a.txt 2

Замечание: num_threads = 1 по умолчанию

Полная очистка проекта от мусора:
$ cd ..
$ rm -rf build
